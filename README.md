# Multi-Agent Train Scheduling: When Should Trains Coordinate?

CSC649 Assignment 1: a problem formulation, requirements and technology brief on how trains should coordinate with each other during rail disruptions.

## Problem statement

Rail dispatchers and operators must keep trains moving when a disruption occurs on shared track, and passengers bear the cost when they cannot. A single delayed train can hold up others that need the same track section, producing secondary delays and, in the worst case, a deadlock where trains block each other. Trains can avoid this by communicating, but constant communication adds message overhead, while too little leaves each train unaware of upcoming conflicts. It is therefore unclear when trains should coordinate during a disruption.
